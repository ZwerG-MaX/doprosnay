## Что было сделано

### 1. Создан компонент AudioControl

**Файл:** `src/components/AudioControl.tsx`

Встроенный аудиоинтерфейс для управления подключением к Mumble серверу напрямую из пульта.

**Функционал:**
- ✅ Подключение к Mumble через WebSocket proxy
- ✅ Управление микрофоном (mute/unmute)
- ✅ Управление звуком (deafen/undeafen)
- ✅ Регуляторы громкости входа/выхода
- ✅ Список пользователей в комнате
- ✅ Визуализация статуса подключения
- ✅ Интеграция с Web Audio API

**Особенности:**
- Использует `navigator.mediaDevices.getUserMedia` для доступа к микрофону
- Подключается к mumble-web-proxy через WebSocket на порту 64737
- Автоматическая обработка ошибок и переподключения
- Адаптивный дизайн для темной/светлой темы

### 2. Создан компонент AdminSettings

**Файл:** `src/components/AdminSettings.tsx`

Модальное окно настроек администратора с вкладками.

**Вкладки:**
- **Аудио** — встроенный AudioControl + ссылка на mumble-web
- **Серверы** — настройки Mumble, PostgreSQL, MediaMTX
- **Пользователи** — управление доступом и правами
- **Система** — информация о системе, логи, опасные действия

**Особенности:**
- Полноэкранное модальное окно
- Таблицы с настройками серверов
- Информация о системе и логах
- Кнопки для опасных действий (очистка кэша, сброс настроек)

## Как использовать

### Встроенный аудиоинтерфейс

1. Откройте пульт наблюдения
2. Нажмите кнопку "Аудиоконтроль" или "Настройки" → "Аудио"
3. Нажмите "Подключиться к Mumble"
4. Разрешите доступ к микрофону
5. Управляйте микрофоном и звуком через кнопки

### Альтернативный mumble-web

1. Откройте настройки администратора
2. Перейдите на вкладку "Аудио"
3. Нажмите "Открыть mumble-web"
4. Используйте полнофункциональный интерфейс mumble-web

## Технические детали

### WebSocket подключение

```typescript
const wsUrl = `ws://${window.location.hostname}:64737`;
const ws = new WebSocket(wsUrl);
```

### Audio API

```typescript
const stream = await navigator.mediaDevices.getUserMedia({ 
  audio: {
    echoCancellation: true,
    noiseSuppression: true,
    autoGainControl: true
  } 
});
```

### Управление микрофоном

```typescript
const audioTracks = mediaStreamRef.current.getAudioTracks();
audioTracks.forEach(track => {
  track.enabled = isMuted;
});
```
